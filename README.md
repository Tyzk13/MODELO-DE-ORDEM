# Meu Orçamento

App para controlar o orçamento do mês, feito para usar no celular.

**Link para abrir no celular:** https://claude.ai/artifact/YEHd452K8WXwtNsF1HKaSo

Aberto por esse link (logado na sua conta Claude), os dados ficam salvos na sua conta e sincronizam entre celular e computador. O arquivo `index.html` também funciona aberto direto no navegador; nesse caso os dados ficam só naquele aparelho.

Dica: no celular, use "Adicionar à tela de início" no navegador para abrir como um app.

## O que dá para fazer

- **Renda**: cadastre salário e rendas extras.
- **Contas fixas**: luz, água, aluguel, internet… com dia de vencimento e marcação de "paga". Elas são copiadas automaticamente para o mês seguinte.
- **Botão + Gasto**: lança um gasto em segundos (valor, categoria, pronto), avisando antes se vai estourar algum limite.
- **Quanto posso gastar hoje**: o valor do dia, recalculado conforme você gasta.
- **Limites**: defina um limite geral do mês e limites por categoria. As barras ficam amarelas a partir de 80% e vermelhas quando passa do limite. 
- **Meta de economia**: quanto você quer guardar no mês.
- **Resumo**: sobra do mês e quanto você ainda pode gastar por dia até o fim do mês.
- **Alertas**: limites perto de estourar, contas vencendo em até 3 dias ou atrasadas, saldo negativo.
- **Backup**: exporte/importe tudo em um arquivo `.json`.
